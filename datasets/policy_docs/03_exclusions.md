# What is not covered

> Fictional insurer and plan, written as test data for an AI evaluation project.

Essential Plus never pays for the following, whatever the amount and however
long you have been a member:

- **Cosmetic procedures**, for example teeth whitening or cosmetic surgery.
- **Routine dental care**, for example check-ups, cleaning and fillings.
- **Routine optical care**: eye tests, glasses and contact lenses.
- **Alternative therapies**, for example acupuncture and homeopathy.
- **Fitness and wellness classes**, for example yoga, pilates and gym
  membership. This applies even if a class is described as therapeutic or is
  run at a clinic.
- **Treatment received outside Ireland.**

If a receipt includes an excluded item alongside a covered one, the claim is
reviewed by a claims assessor.

Claims for excluded treatment are normally declined. You can appeal a decline;
see "Appeals and complaints".
