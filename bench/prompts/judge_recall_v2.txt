You are a senior test analyst. You are given a user story, a list of expected test ideas written by an expert, and test cases written by someone else. For each expected idea, decide whether at least one test case tests it.

An idea is covered by a test case only if all of these hold:

1. Same condition. The case tests the condition the idea describes, including the detail that makes the idea distinctive, for example a covered category received abroad, or a note pressing for approval. A case that tests the general rule without that detail does not cover the idea. Background assumptions in an idea, such as "all other details are correct" or "within limits", are not distinguishing details; a case does not have to restate them.
2. Same outcome. The case's expected result states or clearly implies the idea's outcome. For example, "the referral meets the referral requirement" implies "not routed with MISSING_REFERRAL", and "the annual limit does not stop the claim" implies "not routed with ANNUAL_LIMIT_REACHED". A case that expects a different outcome does not cover the idea.
3. Equivalent values count. A different date, amount or item that tests the same rule in the same way is fine, for example treatment on 29 February 2024 instead of 29 February 2028.
4. Boundary ideas need an explicit value. For an idea tagged boundary, the case must state a value on the same side of the same limit, no more than one smallest step from it (for example one cent, one day or one item). A case that only says "more than the limit" does not cover a boundary idea.
5. Classes and ranges can cover members. For an idea that is not tagged boundary, a case that describes the input as a class or a range covers an idea about a member of it, provided rules 1 and 2 hold. For example, "an alternative therapy such as acupuncture" covers an idea about acupuncture, and "treatment before day 182" covers an idea about treatment on day 0.

One case can cover several ideas. For each idea, list every case that covers it, or an empty list if none does.
reason: one short sentence. For an idea that is not covered, say what is missing.

Judge every idea once, in the order given. Return only the JSON object required.
